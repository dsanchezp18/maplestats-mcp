### Added

- `reproduce_code`: `language="sas"` writes a SAS program (Base SAS 9.4M5 or later) that fetches the same data with `PROC HTTP`, reads it as text, applies the tool's filters and sort, and runs the standard cleaning (snake_case names of at most 32 characters, trimmed text, numbers stored as text converted, codes and leading-zero columns kept as text). The prepared table is `work.maple_data`. SAS reads delimited text, ZIP archives and Excel workbooks; for JSON, SDMX, HTML and feed sources, and for sources whose steps run in Python, the result carries no SAS script and a note says why. `language="all"` now includes SAS where it applies, and `summary=True` leaves it out, as it does for Stata and Julia. The programs were written from SAS's documentation and are checked structurally, not run in a SAS session.

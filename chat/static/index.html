MapleStats Chat

Ask about Canadian open data. A small, cheap model looks the answer up live through the MapleStats MCP server. Under each answer: a chart and a table of the data the server returned, and its sources.

Demo only: answers can be wrong, so check the source it names. The chart and table show the data the server returned, not the model's text. Questions are sent to the model provider; this chat is saved in your browser only.

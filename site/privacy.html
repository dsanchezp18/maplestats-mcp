{en}Privacy policy{fr}Politique de confidentialité{/}

{en}MapleStats MCP has no accounts. Requests are processed using the data handling described below. This page covers the hosted endpoint at https://maplestats-mcp.onrender.com/mcp. Last updated 9 October 2026.{fr}MapleStats MCP n'a aucun compte. Les requêtes sont traitées selon les pratiques décrites ci-dessous. Cette page porte sur le point d'accès hébergé à l'adresse https://maplestats-mcp.onrender.com/mcp. Dernière mise à jour : 9 octobre 2026.{/}

{en}Data we collect{fr}Données recueillies{/}

{en}The server asks for no sign-in. It receives a network address and the arguments sent with each tool call. To answer a request it receives the tool name and arguments your AI assistant sends, such as a search phrase, a table number or a city name. It does not automatically receive your full conversation, but arguments can contain text from it. The data it returns comes from public sources.{fr}Le serveur ne demande aucune connexion. Il reçoit une adresse réseau et les arguments envoyés avec chaque appel d'outil. Pour répondre à une requête, il reçoit le nom de l'outil et les arguments que votre assistant IA envoie, comme une expression de recherche, un numéro de tableau ou le nom d'une ville. Il ne reçoit pas automatiquement toute votre conversation, mais les arguments peuvent en contenir des passages. Les données qu'il renvoie viennent de sources publiques.{/}

{en}How the data is used and stored{fr}Utilisation et conservation{/}

  • {en}Tool arguments are used to run the request. Tool failure logs omit argument values and exception text. HTTP access logs can include the network address, method, path and status of a request.{fr}Les arguments servent à exécuter la requête. Les journaux d'erreurs des outils omettent les valeurs des arguments et le texte des exceptions. Les journaux d'accès HTTP peuvent inclure l'adresse réseau, la méthode, le chemin et l'état d'une requête.{/}
  • {en}A count of tool runs is kept in memory by tool name, day and success or failure, and is public at /stats. It holds no arguments, no client addresses and nothing that identifies a person. It resets when the server restarts.{fr}Un compte des exécutions est gardé en mémoire par nom d'outil, par jour et selon la réussite ou l'échec, et il est public à /stats. Il ne contient ni arguments, ni adresses de clients, ni rien qui identifie une personne. Il repart à zéro au redémarrage du serveur.{/}
  • {en}A client's network address is held in memory to apply the rate limit (60 requests a minute). Entries with no requests in the last minute are removed when another client makes a request; they can remain longer while the server is idle.{fr}L'adresse réseau d'un client est gardée en mémoire pour appliquer la limite de débit (60 requêtes par minute). Les entrées sans requête depuis une minute sont supprimées lors d'une requête d'un autre client; elles peuvent rester plus longtemps si le serveur est inactif.{/}
  • {en}Recent responses from the public sources are cached in memory to save time. The cache can include search phrases and filters in its keys or responses. Entries expire or are removed as space is needed, and the in-memory cache disappears when the server stops. Public source files can also be cached on temporary disk until removed or cleared by the host.{fr}Les réponses récentes des sources publiques sont gardées en mémoire cache pour gagner du temps. Les clés ou les réponses du cache peuvent contenir des expressions de recherche et des filtres. Les entrées expirent ou sont supprimées selon l'espace disponible, et le cache en mémoire disparaît à l'arrêt du serveur. Des fichiers de sources publiques peuvent aussi être gardés sur un disque temporaire jusqu'à leur suppression ou au nettoyage par l'hébergeur.{/}

{en}Retention{fr}Durée de conservation{/}

{en}The in-memory items above last until expiry, cleanup or the end of the server process. Public source files can remain on temporary disk. HTTP access logs are retained under the host's practices. Files that a tool returns, such as an Excel workbook, are sent to you in the response and are not kept.{fr}Les éléments en mémoire décrits plus haut restent jusqu'à leur expiration, leur nettoyage ou la fin du processus du serveur. Des fichiers de sources publiques peuvent rester sur le disque temporaire. Les journaux d'accès HTTP sont conservés selon les pratiques de l'hébergeur. Les fichiers qu'un outil renvoie, comme un classeur Excel, vous sont envoyés dans la réponse et ne sont pas conservés.{/}

{en}Who else sees a request{fr}Qui d'autre voit une requête{/}

  • {en}The publisher of the data. To run a tool, the server sends a request to the publisher's service, such as Statistics Canada, the Bank of Canada or a city's open-data portal. The publisher sees that request and the server's address, not yours, under its own terms.{fr}L'éditeur des données. Pour exécuter un outil, le serveur envoie une requête au service de l'éditeur, comme Statistique Canada, la Banque du Canada ou le portail de données ouvertes d'une ville. L'éditeur voit cette requête et l'adresse du serveur, non la vôtre, selon ses propres conditions.{/}
  • {en}The host. The endpoint runs on Render, which keeps its own request logs under its privacy policy and terms.{fr}L'hébergeur. Le point d'accès fonctionne sur Render, qui tient ses propres journaux de requêtes selon sa politique de confidentialité et ses conditions.{/}
  • {en}Your AI assistant. Claude or any other client handles your conversation under its own privacy policy. MapleStats receives only what the client includes in tool calls.{fr}Votre assistant IA. Claude ou tout autre client traite votre conversation selon sa propre politique de confidentialité. MapleStats reçoit uniquement ce que le client inclut dans les appels d'outils.{/}

{en}MapleStats does not sell data, share it with advertisers, run analytics or tracking services, or use requests to train models.{fr}MapleStats ne vend aucune donnée, ne la partage avec aucun annonceur, n'utilise aucun service d'analytique ou de suivi et n'emploie pas les requêtes pour entraîner des modèles.{/}

{en}Keeping everything on your machine{fr}Tout garder sur votre machine{/}

{en}MapleStats is open source. If you run it locally, nothing reaches the hosted server, and the only outside requests are those to the publishers.{fr}MapleStats est un logiciel libre. Si vous l'exécutez en local, rien n'atteint le serveur hébergé et les seules requêtes externes sont celles envoyées aux éditeurs.{/}

{en}Children{fr}Enfants{/}

{en}The service is not directed at children. The request handling described above applies to all users.{fr}Le service ne s'adresse pas aux enfants. Les pratiques décrites ci-dessus s'appliquent à tous les utilisateurs.{/}

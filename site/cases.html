{en}MCP stands for Model Context Protocol, an open standard for connecting AI agents to tools and data. Think of it as a USB-C port for AI: any agent that speaks it can plug into any server that does. MapleStats is that plug for Canadian data: {{tool_count}} tools from federal agencies, provinces, cities and open-data catalogues, behind one connection.{fr}MCP signifie Model Context Protocol, une norme ouverte qui relie les agents IA aux outils et aux données. Voyez-le comme un port USB-C pour l'IA : tout agent qui le parle peut se brancher sur tout serveur qui le parle aussi. MapleStats est cette prise pour les données canadiennes : {{tool_count}} outils d'organismes fédéraux, de provinces, de villes et de catalogues de données ouvertes, derrière une seule connexion.{/}

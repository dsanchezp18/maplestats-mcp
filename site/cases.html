{en}One MCP for the Agent to help them all.{fr}Un MCP pour que l'Agent les aide tous.{/}

{en}MCP stands for Model Context Protocol, an open standard for connecting AI agents to tools and data. Think of it as a USB-C port for AI: any agent that speaks it can plug into any server that does. MapleStats is that plug for Canadian data, so the same agent can serve the statistician, the demographer, the economist and the analyst.{fr}MCP signifie Model Context Protocol, une norme ouverte qui relie les agents IA aux outils et aux données. Voyez-le comme un port USB-C pour l'IA : tout agent qui le parle peut se brancher sur tout serveur qui le parle aussi. MapleStats est cette prise pour les données canadiennes, et le même agent peut servir le statisticien, le démographe, l'économiste et l'analyste.{/}

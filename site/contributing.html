{en}Contributing{fr}Contribuer{/}

{en}Help build MapleStats{fr}Aidez à bâtir MapleStats{/}

{en}MapleStats is open source and grows one source at a time. You can help without writing any code: report a wrong number, suggest a source, or share how you used it. If you do write code, this page walks through the whole process, from the first issue to the live site.{fr}MapleStats est un logiciel libre qui grandit une source à la fois. Vous pouvez aider sans écrire une ligne de code : signaler un chiffre erroné, proposer une source ou raconter comment vous l'avez utilisé. Si vous écrivez du code, cette page décrit tout le processus, du premier signalement jusqu'au site en ligne.{/}

{en}How to contribute code{fr}Comment contribuer du code{/}

01

{en}Open an issue first{fr}Ouvrez d'abord un signalement{/}

{en}Tell me what you want to add or fix before you write code. For a new source, link its API documentation or data page.{fr}Dites-moi ce que vous voulez ajouter ou corriger avant d'écrire du code. Pour une nouvelle source, donnez le lien vers la documentation de son API ou sa page de données.{/}

02

{en}Set up and read AGENTS.md{fr}Installez et lisez AGENTS.md{/}

{en}Fork and clone the repository, then install it with uv. Read AGENTS.md before you start, whether you are a person or an agent. It shows how a module is laid out, what every tool returns, and three lines you should not remove.{fr}Faites une bifurcation (fork) du dépôt, clonez-le et installez-le avec uv. Lisez AGENTS.md avant de commencer, que vous soyez une personne ou un agent. Il montre la structure d'un module, ce que renvoie chaque outil et trois lignes à ne pas supprimer.{/}

03

{en}Build against the real API{fr}Travaillez avec la vraie API{/}

{en}Start a new source from a copy of modules/_example/. Before you call it done, run every function against the live API with realistic arguments. Mocked tests only check your own assumptions: when I ran the 32 Statistics Canada tools live, I found nine bugs the mocks had missed.{fr}Partez d'une copie de modules/_example/ pour une nouvelle source. Avant de la considérer comme terminée, lancez chaque fonction sur l'API réelle, avec des arguments réalistes. Les tests simulés ne vérifient que vos propres hypothèses : en lançant en direct les 32 outils de Statistique Canada, j'ai trouvé neuf bogues que les simulations avaient manqués.{/}

04

{en}Test it, and list it{fr}Testez-le et répertoriez-le{/}

{en}Add mocked unit tests with pytest-httpx, and a live smoke test for every tool in scripts/smoke_test_modules.py. Add the module to SOURCES in scripts/build_site.py, and a title to FAMILIES for each sub-API folder; a test fails if one is missing. A new CKAN, ArcGIS Hub or Socrata portal is not a new module: add it to that family's PORTALS and its province to PORTAL_PLACES.{fr}Ajoutez des tests unitaires simulés avec pytest-httpx, et un test en direct pour chaque outil dans scripts/smoke_test_modules.py. Ajoutez le module à SOURCES dans scripts/build_site.py, et un titre à FAMILIES pour chaque dossier de sous-API; un test échoue s'il en manque un. Un nouveau portail CKAN, ArcGIS Hub ou Socrata n'est pas un nouveau module : ajoutez-le aux PORTALS de cette famille, et sa province à PORTAL_PLACES.{/}

05

{en}Run the checks{fr}Lancez les vérifications{/}

{en}These are the four checks CI runs. All four must pass before I review a pull request.{fr}Ce sont les quatre vérifications de l'intégration continue. Les quatre doivent réussir avant que j'examine une demande de fusion.{/}

06

{en}Open a pull request{fr}Ouvrez une demande de fusion{/}

{en}Say what changed and how you checked it against the live source. CI runs the checks on every supported Python version. Small pull requests get merged faster.{fr}Dites ce qui a changé et comment vous l'avez vérifié auprès de la source en direct. L'intégration continue lance les vérifications sous chaque version de Python prise en charge. Les petites demandes sont fusionnées plus vite.{/}

07

{en}After the merge{fr}Après la fusion{/}

{en}When the checks pass on the main branch, the website rebuilds, so a new tool shows up on the Tools page and in the search. The demo data change only when someone runs scripts/capture_cases.py and commits the result. Every Monday, the live smoke tests run against the real APIs to catch changes at the source.{fr}Quand les vérifications réussissent sur la branche principale, le site se reconstruit : un nouvel outil apparaît dans la page Outils et dans la recherche. Les données des démos ne changent que lorsque quelqu'un lance scripts/capture_cases.py et valide le résultat. Chaque lundi, les tests en direct tournent sur les vraies API pour repérer un changement à la source.{/}

{en}With a coding agent{fr}Avec un agent de programmation{/}

{en}The repository is set up for coding agents. Point yours at AGENTS.md first (CLAUDE.md in the repository points there too), and it follows the same process and runs the same checks.{fr}Le dépôt est conçu pour les agents de programmation. Dirigez d'abord le vôtre vers AGENTS.md (le fichier CLAUDE.md du dépôt y renvoie aussi); il suivra le même processus et lancera les mêmes vérifications.{/}

{en}Read AGENTS.md in this repository, then add a module for [the source] following it.{fr}Lis AGENTS.md dans ce dépôt, puis ajoute un module pour [la source] en le suivant.{/}

{en}Ground rules{fr}Règles de base{/}

  • {en}Contributions are released under the project's MIT licence.{fr}Les contributions sont publiées sous la licence MIT du projet.{/}
  • {en}The data stay with their publishers, so do not commit copies of a source's data.{fr}Les données restent chez leurs éditeurs : ne versez pas de copies des données d'une source dans le dépôt.{/}
  • {en}No API keys or credentials in the code. Every source so far works without one.{fr}Aucune clé d'API ni aucun identifiant dans le code. Toutes les sources actuelles fonctionnent sans.{/}
  • {en}Found a security problem? Report it privately through GitHub's private vulnerability reporting, not in a public issue; see the security policy.{fr}Vous avez trouvé une faille de sécurité ? Signalez-la en privé par le signalement privé de vulnérabilités de GitHub, pas dans un signalement public; voir la politique de sécurité.{/}
  • {en}English and French together: a tool without French keywords cannot be found by a French query.{fr}L'anglais et le français ensemble : un outil sans mots-clés français est introuvable par une requête en français.{/}

{en}About MapleStats{fr}À propos de MapleStats{/}

{en}MapleStats is an open-source MCP server that gives AI agents one way into Canadian open data, in English and French.{fr}MapleStats est un serveur MCP libre qui donne aux agents IA un seul accès aux données ouvertes canadiennes, en français et en anglais.{/}

{en}What it is{fr}Ce que c'est{/}

{en}One server with {{tool_count}} tools across {{module_count}} modules: Statistics Canada, the Bank of Canada, CMHC, {{other_national_count}} other federal sources and {{local_catalogue_count}} provincial, territorial and city catalogues. A connected agent sees three of them, plan_query, search_tools and call_tool, and finds the rest by searching in plain language.{fr}Un seul serveur, {{tool_count}} outils répartis en {{module_count}} modules : Statistique Canada, la Banque du Canada, la SCHL, {{other_national_count}} autres sources fédérales et {{local_catalogue_count}} catalogues provinciaux, territoriaux et municipaux. Un agent connecté en voit trois, plan_query, search_tools et call_tool, et trouve les autres par une recherche en langage courant.{/}

{en}How it works{fr}Comment il fonctionne{/}

{en}MapleStats centralizes the interface, not the data. It keeps no copy: every call goes to the publisher, and every result names its source, the exact URL and the time of the query. Any data call can also come back as an R, Python, Stata or Julia script, so the analysis can be rerun without the agent.{fr}MapleStats centralise l'interface, pas les données. Il ne garde aucune copie : chaque appel va à l'éditeur, et chaque résultat nomme sa source, l'URL exacte et l'heure de la requête. Tout appel de données peut aussi revenir sous forme de script R, Python, Stata ou Julia, pour refaire l'analyse sans l'agent.{/}

{en}It runs on your machine over stdio, with no account or API key. The code is on GitHub under the MIT licence. Version {{version}} is a beta; the roadmap lists what is covered and what is next.{fr}Il s'exécute sur votre machine par stdio, sans compte ni clé d'API. Le code est sur GitHub, sous licence MIT. La version {{version}} est une bêta; la feuille de route indique ce qui est couvert et ce qui suit.{/}

{en}Other MCP servers for Canadian data{fr}Autres serveurs MCP de données canadiennes{/}

{en}These do what MapleStats does, for some or all of the same sources. A narrower server is simpler to set up and gives the agent fewer tools to choose from, which can be the better trade.{fr}Ils font ce que fait MapleStats, pour une partie ou la totalité des mêmes sources. Un serveur plus étroit est plus simple à installer et offre moins d'outils à l'agent, ce qui peut être le meilleur compromis.{/}

  • mcp-canadaReyemTech · Python {en}The closest to MapleStats in scope: bilingual tools for federal, provincial and municipal APIs, with a local SQLite store. It covers some sources MapleStats does not, such as Health Canada's drug database.{fr}Le plus proche de MapleStats par sa portée : des outils bilingues pour des API fédérales, provinciales et municipales, avec un stockage SQLite local. Il couvre des sources que MapleStats n'a pas, comme la base de données sur les produits pharmaceutiques de Santé Canada.{/}
  • mcp-statcanAryan-Jhaveri · Python {en}Statistics Canada only, through both its Web Data Service and its SDMX API, with a hosted endpoint, a command-line tool and SQLite storage. A good choice if StatCan tables are all you need.{fr}Statistique Canada seulement, par son Service de données Web et son API SDMX, avec un point d'accès hébergé, un outil en ligne de commande et un stockage SQLite. Un bon choix si vous n'avez besoin que des tableaux de StatCan.{/}
  • statcan-mcpbank-of-canada-mcparose26 · TypeScript {en}Two small servers, one for StatCan tables and one for Bank of Canada series, each run with npx and no key.{fr}Deux petits serveurs, l'un pour les tableaux de StatCan, l'autre pour les séries de la Banque du Canada, lancés chacun avec npx, sans clé.{/}
  • mcp-statcanmcp-bank-of-canadamcp-opendata-canadapipeworx-io · TypeScript {en}One small server each for StatCan, the Bank of Canada and open.canada.ca, run locally or through the hosted Pipeworx gateway, which also reaches many sources outside Canada.{fr}Un petit serveur chacun pour StatCan, la Banque du Canada et ouvert.canada.ca, à lancer localement ou par la passerelle hébergée de Pipeworx, qui donne aussi accès à de nombreuses sources hors du Canada.{/}
  • gov-ca-mcpkrunal16-c · Python {en}Two servers: one searches the federal open-data catalogue and several provincial portals, the other queries transport infrastructure such as bridges, airports and railways.{fr}Deux serveurs : l'un cherche dans le catalogue fédéral de données ouvertes et dans plusieurs portails provinciaux, l'autre interroge les infrastructures de transport comme les ponts, les aéroports et les chemins de fer.{/}
  • ckan-mcp-serverondata · TypeScript {en}A general server for any CKAN portal, open.canada.ca among them, with a hosted endpoint. It is not built for Canada, so it does not reach StatCan tables or Bank of Canada series.{fr}Un serveur général pour tout portail CKAN, dont ouvert.canada.ca, avec un point d'accès hébergé. Il n'est pas conçu pour le Canada et n'atteint donc ni les tableaux de StatCan ni les séries de la Banque du Canada.{/}

{en}The official MCP Registry, Glama and PulseMCP list more servers for single topics, such as elections, case law or procurement.{fr}Le registre MCP officiel, Glama et PulseMCP recensent d'autres serveurs consacrés à un seul sujet, comme les élections, la jurisprudence ou les marchés publics.{/}

{en}R and Python packages{fr}Paquets R et Python{/}

{en}Libraries, not MCP servers: you write the code and get data frames back, with no agent in between. For reproducible analysis they are often the better tool. Most of the R packages are by Jens von Bergmann (mountainMath) and co-authors.{fr}Des bibliothèques, pas des serveurs MCP : vous écrivez le code et obtenez des tableaux de données, sans agent entre les deux. Pour une analyse reproductible, ce sont souvent de meilleurs outils. La plupart des paquets R sont de Jens von Bergmann (mountainMath) et de ses coauteurs.{/}

  • cansimmountainMath · R {en}StatCan tables and vectors as tidy data frames, with metadata and local caching. If you work in R and only need StatCan tables, it is the most direct route; the R code MapleStats writes uses it.{fr}Les tableaux et vecteurs de StatCan sous forme de tableaux de données ordonnés, avec métadonnées et cache local. Si vous travaillez en R et n'avez besoin que des tableaux de StatCan, c'est la voie la plus directe; le code R qu'écrit MapleStats l'utilise.{/}
  • cancensusmountainMath · R {en}Census data and boundaries through the CensusMapper API, ready for maps. It needs a free API key. For census mapping in R it does more than MapleStats.{fr}Les données et les limites du recensement par l'API de CensusMapper, prêtes pour la cartographie. Il demande une clé d'API gratuite. Pour cartographier le recensement en R, il en fait plus que MapleStats.{/}
  • tongfenmountainMath · R {en}Makes data on different geographies comparable, such as census tracts whose boundaries changed between censuses. MapleStats has nothing like it.{fr}Rend comparables des données sur des géographies différentes, comme des secteurs de recensement dont les limites ont changé d'un recensement à l'autre. MapleStats n'offre rien de tel.{/}
  • cmhcmountainMath · R {en}Data from CMHC's Housing Market Information Portal, such as starts, rents and vacancy rates. MapleStats's CMHC module was checked against it.{fr}Les données du Portail de l'information sur le marché de l'habitation de la SCHL, comme les mises en chantier, les loyers et les taux d'inoccupation. Le module SCHL de MapleStats a été vérifié par rapport à lui.{/}
  • canpumfmountainMath · R {en}Downloads StatCan's public use microdata files and labels them, in a DuckDB database.{fr}Télécharge les fichiers de microdonnées à grande diffusion de StatCan et les étiquette, dans une base DuckDB.{/}
  • canbankmountainMath · R {en}Bank of Canada Valet series and groups in R. It installs from GitHub, not CRAN.{fr}Les séries et groupes Valet de la Banque du Canada en R. Il s'installe depuis GitHub, pas depuis CRAN.{/}
  • statcanRwarint · R {en}Another R client for the StatCan Web Data Service, returning whole tables in English or French.{fr}Un autre client R du Service de données Web de StatCan, qui renvoie des tableaux complets en français ou en anglais.{/}
  • stats_canianepreston · Python {en}StatCan tables and vectors in pandas: the closest Python counterpart to cansim.{fr}Les tableaux et vecteurs de StatCan dans pandas : l'équivalent Python le plus proche de cansim.{/}
  • pycancensusdshkol · Python {en}A Python port of cancensus, with the same CensusMapper data and the same free key.{fr}Un portage Python de cancensus, avec les mêmes données CensusMapper et la même clé gratuite.{/}

{en}StatCan's data do not come from one place. Tables and time series come from one service. Classifications such as NAICS, the 2021 Census Profile, the public use microdata files and The Daily each come from another. Each service has its own identifiers and its own ways of failing. Someone asking about prices should not need to know any of this, and neither should the agent working for them.{fr}Les données de Statistique Canada ne viennent pas d'un seul endroit. Les tableaux et les séries chronologiques viennent d'un service. Les classifications comme le SCIAN, le Profil du recensement de 2021, les fichiers de microdonnées à grande diffusion et Le Quotidien viennent chacun d'un autre. Chaque service a ses propres identifiants et ses propres façons d'échouer. Une personne qui pose une question sur les prix ne devrait pas avoir à savoir tout cela, pas plus que l'agent qui travaille pour elle.{/}

{en}Finding a table{fr}Trouver un tableau{/}

{{count_tables}}

{en}tables were in StatCan's list of tables on {{cases_captured}}. Every table search reads that list.{fr}tableaux figuraient dans la liste des tableaux de Statistique Canada le {{cases_captured}}. Chaque recherche de tableau lit cette liste.{/}

{en}Every StatCan table has a number, such as 18-10-0004 for the Consumer Price Index. The table search finds a table by its number, or by matching every word of a query against the English and French titles, ignoring accents and case. That is how "consumer price index" finds the CPI tables.{fr}Chaque tableau de Statistique Canada a un numéro, comme 18-10-0004 pour l'Indice des prix à la consommation. La recherche trouve un tableau par son numéro, ou en retrouvant chaque mot de la requête dans les titres français et anglais, sans égard aux accents ni à la casse. C'est ainsi que « indice des prix à la consommation » trouve les tableaux de l'IPC.{/}

{en}Title matching has a limit. A word such as a province's name is usually inside a table, not in its title. When no title holds every word, the tool returns the closest matches and says how many words each one matched. The agent can then look inside a table or search again in StatCan's own terms.{fr}La correspondance sur les titres a une limite. Un mot comme le nom d'une province se trouve d'habitude dans le tableau, pas dans son titre. Quand aucun titre ne contient tous les mots, l'outil renvoie les tableaux les plus proches et indique combien de mots chacun retrouve. L'agent peut alors regarder dans un tableau ou chercher de nouveau avec les termes de Statistique Canada.{/}

{en}One rule matters more to me than the others: the server never rescales a value. Some tables publish figures in thousands or millions, and StatCan sends a code with each value that says which. MapleStats passes the value on exactly as StatCan sent it, with that code beside it. Scaling takes one multiplication, and I would rather it happen where the person using the number can see it.{fr}Une règle compte plus que les autres pour moi : le serveur ne remet jamais une valeur à l'échelle. Certains tableaux publient leurs chiffres en milliers ou en millions, et Statistique Canada envoie avec chaque valeur un code qui le précise. MapleStats transmet la valeur exactement comme Statistique Canada l'a envoyée, avec ce code à côté. La mise à l'échelle tient en une multiplication, et je préfère qu'elle se fasse là où la personne qui utilise le chiffre peut la voir.{/}

{en}A handful of series come back in the response itself. For a whole table, or hundreds of series, the server returns a link to the table's CSV file instead. For a slice of a large table, such as every detailed geography, it uses StatCan's SDMX service, which does the filtering on StatCan's side.{fr}Quelques séries reviennent directement dans la réponse. Pour un tableau entier, ou des centaines de séries, le serveur renvoie plutôt un lien vers le fichier CSV du tableau. Pour une tranche d'un grand tableau, comme chaque géographie détaillée, il passe par le service SDMX de Statistique Canada, qui fait le filtrage de son côté.{/}

{en}Survey microdata{fr}Microdonnées d'enquête{/}

{{count_pumf}}

{en}microdata products in StatCan's Data catalogue on {{cases_captured}}.{fr}produits de microdonnées dans le catalogue Données de Statistique Canada le {{cases_captured}}.{/}

{en}Tables are aggregates. A public use microdata file holds the survey records themselves, one row per respondent, with weights that scale the sample up to the population. MapleStats can find these files in StatCan's catalogue, read a file's codebook before downloading it, and tabulate the file with its weights. It reads files in CSV or fixed-width text and, when a file comes only as SAS, SPSS or Stata data (Canada's Core Public Infrastructure Survey, for one), those formats too. The tabulation downloads whole files: the first call on a file can time out while it downloads, and a retry uses the saved copy, on the hosted server as on a local install.{fr}Les tableaux sont des agrégats. Un fichier de microdonnées à grande diffusion contient les enregistrements de l'enquête eux-mêmes, une ligne par répondant, avec des poids qui ramènent l'échantillon à l'échelle de la population. MapleStats peut trouver ces fichiers dans le catalogue de Statistique Canada, lire le dictionnaire d'un fichier avant de le télécharger et totaliser le fichier avec ses poids. Il lit les fichiers en CSV ou en texte à largeur fixe et, quand un fichier n'existe qu'en données SAS, SPSS ou Stata (l'Enquête sur les infrastructures publiques essentielles du Canada, par exemple), ces formats aussi. Ce calcul télécharge des fichiers entiers : le premier appel sur un fichier peut expirer pendant le téléchargement, et un nouvel essai utilise la copie enregistrée, sur le serveur hébergé comme sur une installation locale.{/}

{en}Two things decide whether a table like this is right. The first is the weight. The tool uses the codebook's main weight, and it checks labels as well as names, because names can mislead: in one survey file, a variable called WTQ_05 is a question about working at night. The second is the sample behind each cell. Every cell carries its unweighted count, and cells with fewer than 30 respondents are flagged.{fr}Deux éléments déterminent la justesse d'un tel tableau. Le premier est le poids. L'outil prend le poids principal du dictionnaire et vérifie les étiquettes en plus des noms, car les noms peuvent tromper : dans un fichier d'enquête, une variable appelée WTQ_05 est une question sur le travail de nuit. Le second est l'échantillon derrière chaque cellule. Chaque cellule indique son effectif non pondéré, et celles de moins de 30 répondants sont signalées.{/}

{en}Standard errors take more care. I add a survey's variance method only after reading its user guide, and I cite the section. {{statcan_variance_count}} files have one so far, the 2021 Census among them. The Labour Force Survey ships no bootstrap weights, so the server builds the calibrated Poisson bootstrap its user guide prescribes (section 6) and returns a standard error, a CV and a quality flag (acceptable, marginal or unacceptable, from the guide's CV bands) for every cell. For any other file, the result gives no standard error and says why. Two demos use the Census file: bachelor's degrees by province and low income across immigrant generations.{fr}Les erreurs-types demandent plus de soin. Je n'ajoute la méthode de variance d'une enquête qu'après avoir lu son guide de l'utilisateur, et j'en cite la section. {{statcan_variance_count}} fichiers en ont une pour l'instant, dont celui du recensement de 2021. L'Enquête sur la population active ne fournit pas de poids bootstrap; le serveur construit donc le bootstrap de Poisson calé que prescrit son guide de l'utilisateur (section 6) et donne pour chaque cellule une erreur-type, un CV et une cote de qualité (acceptable, marginale ou inacceptable, selon les seuils de CV du guide). Pour tout autre fichier, le résultat ne donne pas d'erreur-type et explique pourquoi. Deux démos utilisent le fichier du recensement : le baccalauréat par province et le faible revenu d'une génération d'immigration à l'autre.{/}

{en}What the live services taught me{fr}Ce que les services en direct m'ont appris{/}

{en}I found most of StatCan's quirks by calling the live services, not by reading documentation. Four of them shaped the code.{fr}J'ai trouvé la plupart des particularités de Statistique Canada en appelant les services en direct, pas en lisant la documentation. Quatre d'entre elles ont façonné le code.{/}

{en}The overnight lock. From midnight to 8:30 a.m. Eastern, while StatCan updates its data, some requests are refused. Retrying does not help, so the server stops and says to try again after 8:30 on a release day.{fr}Le verrou de nuit. De minuit à 8 h 30, heure de l'Est, pendant que Statistique Canada met ses données à jour, certaines requêtes sont refusées. Réessayer n'y change rien : le serveur s'arrête et dit de réessayer après 8 h 30 un jour de diffusion.{/}

{en}The connection that hung. Plain connections to statcan.gc.ca timed out with no useful error. Something on StatCan's network blocks connections set up the way a common Python library sets them up by default. One setting fixes it, and the Python scripts MapleStats writes include it too.{fr}La connexion qui restait bloquée. De simples connexions vers statcan.gc.ca expiraient sans message d'erreur utile. Un élément du réseau de Statistique Canada bloque les connexions établies comme le fait par défaut une bibliothèque Python courante. Un seul réglage corrige le problème, et les scripts Python qu'écrit MapleStats l'incluent aussi.{/}

{en}The search that ignored its keyword. StatCan's catalogue search returned the whole reference catalogue, 2,031 documents, unless the session had first visited the catalogue's main page. The server now visits that page first. If a search still comes back unfiltered, it raises an error rather than present the whole catalogue as a match.{fr}La recherche qui ignorait son mot-clé. La recherche des catalogues de Statistique Canada renvoyait tout le catalogue de référence, 2 031 documents, à moins que la session n'ait d'abord visité la page principale du catalogue. Le serveur visite maintenant cette page en premier. Si une recherche revient quand même sans filtre, il lève une erreur plutôt que de présenter tout le catalogue comme résultat.{/}

{en}Testing against the real API. The first version of the StatCan module called only 2 of its 32 tools against the real API before I called it done. Calling all 32 later found 9 more bugs. Tests on made-up data had missed them, because the made-up data shared the code's wrong assumptions. Now no module counts as done until every function has been called against the real service.{fr}Tester sur l'API réelle. La première version du module Statistique Canada n'avait appelé que 2 de ses 32 outils sur l'API réelle quand je l'ai jugée terminée. Appeler les 32 a ensuite révélé 9 autres bogues. Les tests sur des données fictives ne les avaient pas vus, puisque ces données reposaient sur les mêmes hypothèses erronées que le code. Aujourd'hui, aucun module n'est terminé tant que chaque fonction n'a pas été appelée sur le service réel.{/}

{en}Checking an answer{fr}Vérifier une réponse{/}

{en}An agent's answer is only as good as the check someone can run without the agent. After a call, reproduce_code writes an R, Python, Stata or Julia script, or an Excel Power Query, that fetches the same data directly from StatCan. For the CPI call above, the R script is a single call to the cansim package. The scripts keep each value as StatCan sent it and put the scaled number in a separate column. For someone who works in Excel, reproduce_workbook returns the rows as a formatted workbook, with a sheet that records the call, the source and the licence.{fr}La réponse d'un agent ne vaut que la vérification qu'on peut en faire sans lui. Après un appel, reproduce_code écrit un script R, Python, Stata ou Julia, ou une requête Power Query pour Excel, qui récupère les mêmes données directement chez Statistique Canada. Pour l'appel de l'IPC ci-dessus, le script R tient en un seul appel au paquet cansim. Les scripts gardent chaque valeur telle que Statistique Canada l'a envoyée et placent la valeur mise à l'échelle dans une colonne à part. Pour qui travaille dans Excel, reproduce_workbook renvoie les lignes dans un classeur mis en forme, avec une feuille qui consigne l'appel, la source et la licence.{/}
